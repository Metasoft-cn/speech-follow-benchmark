# License review

Code is Apache-2.0. Dataset licensing is separate because software licenses do not automatically cover data.

The initial corpus is written specifically for CSFB or created by a deterministic generator, with no planned use of third-party articles, books, lyrics, commercial copy, recordings, or private user text. CC0 1.0 is selected to make redistribution and reuse of these original/synthetic cases straightforward. Contributors are asked to confirm rights and provenance before submission. This is a project licensing decision, not a legal opinion; any uncertain source is excluded pending review.

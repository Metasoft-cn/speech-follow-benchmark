# Datasets

`golden/cases.jsonl` contains cases expanded from human-authored templates; the count includes variants, not independently handwritten scripts. `synthetic/cases.jsonl` is generated from seed 20260923; `adversarial/cases.jsonl` emphasizes duplicate and prefix traps. `holdout/` is reserved for a future split; all v0.1 cases are currently openly inspectable. `real_asr/` accepts recognized text and labels only, never audio. Hashes and file counts are recorded in `MANIFEST.json`.

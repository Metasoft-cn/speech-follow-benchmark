# Datasets

`golden/cases.jsonl` is retained as the historical v0.1 template-expanded corpus for reproducing the frozen pre-expansion baseline; it is not part of the v0.2.0-preview manifest or benchmark runs. The current manifest lists four distinct layers: curated review-status cases, template-derived cases, seeded synthetic cases, and adversarial cases. Template-derived variants are not independently handwritten scripts. Synthetic cases use seed 20260923; adversarial cases emphasize duplicate, skip, and prefix traps. `holdout/` is reserved for a future split. `real_asr/` accepts redistributable recognized text and labels only, never audio. Hashes and file counts for the current corpus are recorded in `MANIFEST.json`.
